# NEON-CASTER docs

Two illustrated write-ups of how the game was built, made with Claude while
developing it. Open the `index.html` in each folder in a browser (they work
offline; fonts come from Google Fonts when online).

| Folder | What |
|---|---|
| [`showcase/`](showcase/index.html) | The field report: every system in the game shown with real frames from it - the live level editor, a room built from the console, glass, the network, heights and lifts, teleporters, triggers, code terminals, NEXUS, classic vs modern art, the sectors' height designs, performance heat maps, and Windows and macOS. With animations, sounds and before/after sliders. |
| [`roadmap-run/`](roadmap-run/index.html) | The earlier report from the day the roadmap was worked through: glass, data stations, the editors, heights, teleporters, triggers and code puzzles, with the state of each. One file, its pictures built in. |
| [`screenshots/`](screenshots) | The pictures on the front page README. |

These are snapshots of their day: numbers, paths and plans in them are as
they were then.
