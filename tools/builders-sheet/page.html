Part two

The level file

Everything above ends up in one plain text file: neon-caster/levels/custom/customN.txt for your own sector N+10. The editor writes it when you press Ctrl+S, and you can open it in any text editor. Below is how that file is put together, part by part.

How it reads, top to bottom

  1. Comments. Any line starting with '. Ctrl+S keeps only the ones at the very top, so keep your notes there.
  2. The header. key = value lines: the sector's name, its six wall, four floor and two ceiling textures, its light. These come first, before any section.
  3. Sections. A name in brackets, [lights], then one line per thing, numbers split by commas. A section you don't need is left out. Order doesn't matter, but the editor writes them in a fixed order.
  4. The map. [map]: one text row per row of cells, one character per cell, from the map characters above. The rows set the sector's size (square, 16 to 256 across). Its edge is always wall.
  5. Height maps (optional). [floor] and [ceiling] are the same shape as the map, one height character per cell. [liquid], [liquid depth] and the other per-cell maps work the same way.

Coordinates. x counts across from 0 at the left, y down from 0 at the top. A cell is one map character, and 20.5 is the middle of cell 20. In the example, the start > is at x 2, y 2.

A broken file still loads. Numbers out of range are clamped, the edge is made wall, a missing start is added, and a misspelt picture is drawn as wall.png (the console says which).

An example sector, complete

16 × 16: a start room, an ambush room holding the red card (four monsters, then an overcharge), a vault behind the red door with the rocket launcher, and the exit past a tinted, oversized trooper. The level kit checks it clean.

Part three

The console

Press ` in the game or the 3D editor. Anything typed here can also go in a trigger, in autoexec.cfg, or after a + on the command line. Below are all {{NCMDS}} commands, in the game's own words from help NAME.

Typing

  • ; puts several commands on one line: god ; give all ; map 5. A ; inside quotes doesn't split.
  • Tab finishes a command's name. Up/Down bring back earlier lines. PgUp/PgDn or the wheel scroll back, Home/End jump to the oldest or newest line. Ctrl+V pastes and F11 fills the screen.
  • help lists everything; help NAME explains one command. Those are the texts below.
  • Coloured text: yellow is a command's syntax. CAPITALS are values you fill in, [brackets] are optional, and a|b means one of them.

Scripting

  • Triggers run console commands: use 12 8 repeat : light 3 toggle. Building commands rebuild the sector, which resets monsters and pickups, so triggers stick to the "running level" ones (door, light, spawn, message, sound...).
  • Aliases: alias heal "give health ; give armor", with $1–$9 and $* for what follows the alias. unalias NAME removes one. A sector you share should spell commands out, since the player may not have your aliases.
  • autoexec.cfg in the saves folder runs at start-up, before any + commands.
  • Command line: neon-caster.run +map 5 +give all +wait 60 +screenshot five.png +quit. A game started with + commands never saves its settings.
  • Cheats hold achievements. map, god, give, tp and the like mark the game as a cheat run: no achievements or records until a new game. A sector's own triggers don't count.
